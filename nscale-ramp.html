0 · The box and the rebuild script this weekend

Order the second Hetzner dedicated-vCPU box — not the moonshine box, and not inside AWS: the cloud leg only means something if the tunnel genuinely leaves the provider, which is also exactly Nscale's position — a cloud clients connect into from elsewhere. 31 GB is too tight for ~23 nodes; take the tier above (verify current tiers and hourly billing at order time — prices moved June 2026).

Pull the SR Linux container image and prove ECN marks appear under a tc-limited link before anything else is built on that assumption — half of S5 stands on it. If the container dataplane won't mark, the congestion experiments move onto the Linux hosts' own qdiscs and every fabric stage stands regardless.

Write the rebuild skeleton: topology up → per-node configs pushed from git → verify (adjacencies, routes, label path). Hand-config died three times in the HRT lab; it doesn't get a fourth.

Done when: one command brings up the topology and verifies it, so a nightly stop costs nothing.

Both regions' underlays, the 3-node core, TI-LFA on, label path traced end to end. The core carries both SR-MPLS and SRv6 so the comparison later is measured, not asserted.

Tenant VRFs, symmetric IRB, storage VNI, region B thin. The learn.srlinux.dev L2 EVPN tutorial is this stage — reading and building are the same activity. The SR Linux docs (Segment Routing · EVPN · VPN Services) and karneliuk.com sit alongside — the entire published world for the NOS.

Reading that paces it: Chatterjee, Deploying Juniper Data Centers with EVPN VXLAN, starts on the beach — a Juniper author describing the protocol is the second author on the topic the Nokia box is teaching.

Done when: tenant-to-tenant routes across regions through the fabric, all five route types read on the box, configs in git.

3 · S2 — back-end rails, lossless w/c 10 Aug

Two rails + back-end spine, 1:1, GPU hosts dual-homed to both fabrics, RoCEv2 lossless config. The tc rate-limits go in here — veth forwards at memory speed, so without them nothing congests and the lossless config is theatre.

Done when: ECN marks observed under real load on a limited link — same-rail one hop, cross-rail via the spine, measured.

k8s on the GPU hosts, topology-aware placement — the workload the fabric exists for, scheduled with knowledge of the rails.

7 · S5 — the experiments

Incast + ECN tuning · tenant PFC interference (tenant A's congestion pausing tenant B, then per-priority isolation) · collective emulation · inter-region bulk over the core. On the SR side: SR-MPLS vs SRv6 measured on the same core — this is where the job's phase two lands.

Reading that paces it: Filsfils Part II.

8 · The cloud leg — a client connecting in

Real AWS VPC + Transit Gateway + Site-to-Site VPN terminating on bl-a on the Hetzner box — a genuinely inter-provider tunnel: real internet path, real IPsec MTU, eBGP over the tunnel. The exact shape of a corporate client landing on Nscale. The vendor interconnect docs — Direct Connect, ExpressRoute, Cloud Interconnect — ride this step; the differences between the three are where the understanding lives.

Done when: a region-A tenant reaches an instance in the VPC and the route tables on both ends say why.
