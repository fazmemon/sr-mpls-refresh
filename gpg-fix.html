GPG signing — clean reset

Copy each block into Terminal in order. Click a block to select all of it.

0 · Before anything

In 1Password: create an entry "Nscale GPG key" with a generated password. That's the passphrase for step 2.

1 · Wipe the broken GPG state (safe — keyring holds only the dud key)

gpgconf --kill gpg-agent
rm -rf ~/.gnupg
gpg -K
echo "pinentry-program $(brew --prefix)/bin/pinentry-mac" > ~/.gnupg/gpg-agent.conf

The gpg -K prints nothing — that's correct, it just recreates the folder.

2 · Make the new key

gpg --full-generate-key

Answers: ECC (sign and encrypt) → Curve 25519 → expiry 1y → your name → work email exactly as on GitHub → passphrase from 1Password (type it carefully in the dialog).

3 · Copy the public key for GitHub

gpg --armor --export | pbcopy

Prints nothing — the key block is now on the clipboard. GitHub → Settings → SSH and GPG keys → delete the old GPG key → New GPG key → ⌘V → save. Title: "Nscale MacBook".

4 · Point git at the new key + sign everything

git config --global user.signingkey $(gpg -K --keyid-format=long | awk '/^sec/{split($2,a,"/"); print a[2]; exit}')
git config --global commit.gpgsign true
echo 'export GPG_TTY=$(tty)' >> ~/.zshrc
export GPG_TTY=$(tty)

5 · Prove it

cd ~/sign-test 2>/dev/null || { mkdir ~/sign-test && cd ~/sign-test && git init; }
git commit --allow-empty -m "signing test"
git log --show-signature -1

Passphrase dialog appears → tick Save in Keychain → output shows "Good signature". Done — go contribute.
