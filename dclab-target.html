2-AS SR-MPLS: EVPN/VXLAN DC (bl1 = border-leaf → core) · OSPF-SR core · inter-AS SR via BGP-LU → your AS2 exit · EPE peer vs transit · dedicated PIM-SSM market-data (own L3, not overlay) · Traffic Dictator driving SR-TE across both ASes. Not built yet.

DC fabric AS1 SR core / border-leaf AS2 SR inter-AS BGP-LU EPE peer EPE transit PIM-SSM market data controller

bl1 is the border-leaf — it uplinks to both spines like any leaf and it (not the spines) connects down to the core. Market data is a dedicated L3 PIM-SSM segment (md-rx, 10.9.0.0/24) off bl1, kept out of the VXLAN overlay: the (S,G) tree runs mktdata → edge2 → asbr2 → core → bl1 → md-rx (inter-AS SSM, IGMPv3 joins). h1/h2 are plain EVPN tenants. Traffic Dictator peers both ASes (BGP-LS + SR-Policy to core1 and asbr2) so it can steer inter-AS SR-TE and the EPE exit.
15 nodes: 10× cEOS (SR/EVPN) + 5× FRR/Linux (edges, hosts, feed). Loopbacks/ASNs = planned scheme.
