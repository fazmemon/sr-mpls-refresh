The estate — one file, one deploy

Whole footprint = ~/lab/estate/estate.clab.yml (17 nodes). Rebuild after any reboot: ssh lab then ~/lab/estate/rebuild.sh. DC self-configures (startup-config); core restored by the script.

DC = BGP-EVPN/VXLAN, never runs SR. Core = IS-IS-SR (SR-MPLS + SRv6 on one IGP). Borders (bl-a/bl-b) = the seam: terminate the tenant VXLAN into VRF t1, re-originate into VPNv4-over-SR toward the core. The VRF RIB is the pivot — decap to IP, re-encap into SR. Not a tunnel splice.

Working the box — show grammar

1 · show walks contexts; a report keyword ends it (summary / detail / route / brief). "usage: show" = you stopped at a context — it lists the report keywords to finish with.
2 · Lost? Append a garbage token — the parser lists every legal next word.
3 · Bare ping runs in the mgmt VRF — fabric pings need ping network-instance default <addr>.

SR playground — poke the core like you poked the DC

DC you explored via bridge-table mac-table (Type-2/3). SR you explore via the label table + the SID TLVs. On any core node (docker exec -it clab-estate-core1 vtysh):

show isis segment-routing node — every node's SRGB/SRLB/algo (SR "who's who")
show mpls table — the label FIB: 16001-3 = prefix-SIDs, 15xxx = adj-SIDs, implicit-null = 1-hop (PHP)
show ip route 10.0.2.2/32 — the prefix-SID label imposed toward a remote loopback
show isis database detail core2 — see the Prefix-SID / SRv6 Locator sub-TLVs inside the LSP (this is where SR lives in the IGP)
show segment-routing srv6 locator · show ipv6 route 5f00:0:c2::/48 — the SRv6 side (locator learned via IS-IS)

The fun one — watch a swap label appear: triangle = every loopback 1 hop (all implicit-null). Break a link: on the host docker exec clab-estate-core1 ip link set eth1 down. Now core1→core2 goes the long way via core3 (2 hops) → show mpls table on core1 shows a REAL swap label (16002 in → 16002 out), not implicit-null. Bring it back: ip link set eth1 up. That's TI-LFA territory — the reroute.

bl-a build (plane) — core side is proven; CC coaches

Border-leaf bl-a: loopback 10.0.3.1, IS-IS-SR area 49.0002 toward core1 (bl-a:eth3→core1:eth3), MP-BGP VPNv4 to bl-b, tenant VRF t1. Sequence CC will walk you through:

1 · Linux: ip link add t1 type vrf table 100; ip link set t1 up + sysctl net.mpls.platform_labels=1048575 + net.mpls.conf.eth3.input=1
2 · FRR: IS-IS-SR toward core1 (net/is-type/segment-routing on/SRGB/prefix-sid)
3 · FRR: router bgp 65000 VPNv4 to bl-b over loopbacks · vrf t1 with rd/rt vpn + import/export vpn + label vpn export auto
4 · Stage 2 (CC benches first): EVPN-VXLAN VTEP joining the DC overlay → tenant VNI into VRF t1.
