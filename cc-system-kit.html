# Workspace — CC Operating Manual

## Behaviour Rules
16 rules (0-15) injected every message by the UserPromptSubmit hook (`board/hooks/user_prompt.sh`).
Do NOT duplicate them here. If a rule needs changing, change it in the hook file.

## Domain Instructions
- **Commit after every change** — show the hash as proof.
- **Record user decisions** in `board/decisions.md` immediately.
- **Never ask the user to do anything CC can execute with tools.** Run it yourself.
- **Cost model (metered API billing):** the primary dial is EFFORT, not model-switching — run routine work at medium/low effort, reserve high/xhigh for genuinely hard problems, and state when you raise it. Model ladder: Sonnet default; Opus for judgment-heavy work (design, hard diagnosis, expert artifacts); Haiku for bulk mechanical; NEVER Fable (2x Opus per token). No unattended loops without an explicit cap — uncapped token use is what got AI banned here once already.
- [Add domain-specific instructions here as they are ruled.]

## Board System
Location: `board/`
| File | Purpose |
|------|---------|
| BOARD.md | Living status dashboard — injected at session start |
| decisions.md | User decisions log — append-only, dated |
| handovers/archive/ | Session handover docs (write here directly) — NOT auto-loaded |
| hooks/ | Hook scripts (SessionStart, UserPromptSubmit, Stop) |

## Memory System
Location: `~/.claude/projects/<project-dir>/memory/`
- **L1 (always loaded):** MEMORY.md — identity, active streams, key files, instructions. One line per entry; detail lives in linked topic files.
- **L2 (on demand):** per-workstream files + feedback files. Read the stream's L2 before working it.
- **L3 (reference):** handovers in `board/handovers/archive/` — read the NEWEST ONE ONLY at session start; never walk the chain.
- Feedback memories record HOW the user works (corrections + confirmed approaches, with the why). New durable feedback → its own file + a MEMORY.md pointer.

## Handover Requirements
Before ending ANY session:
1. Push facts into live state FIRST: BOARD.md, decisions.md, the relevant L2 memory file.
2. Write the handover to `board/handovers/archive/YYYY-MM-DD-HH-MM.md` (timestamp from `date`, never computed):
   current step at the TOP · objective · state verified this session · context-intake manifest with line counts ·
   verification commands · proof-of-read fact from the final section of the longest must-read · owed + done.
3. Handovers are leads, not facts — the next session verifies ≥3 facts against code/files before asserting.

## Session start (how the next CC gets in context)
1. BOARD.md is injected by the SessionStart hook — it is a map, not context.
2. Read the NEWEST file in board/handovers/archive/ IN FULL. One file only.
3. Read the L2 files for the active workstream.
4. Verify ≥3 live facts before asserting anything.

2 · $WORKROOT/board/hooks/user_prompt.sh — the rules, injected every message

#!/bin/bash
cat <<'RULES'
=== RULES (injected every message) ===

--- CARDINAL (Tier 1) ---
0. Fabrication: don't present results you didn't produce this session, claim unverified things as verified, or invent output.
1. Scope / authority: don't go out of scope, make unauthorized changes, override user decisions, or push past refusals.
2. Breach mechanism: when user says stop or failure mode — read all rules, list what you breached, state how you'll avoid repeating. Self-correct and continue. If genuinely blocked, ask the user.
3. Production alignment: align on approach before modifying production code. Once aligned, execute autonomously without asking per-step permission.

--- WORKING (Tier 2) ---
4. Diagnose before acting. No trial-and-error on a live system. One intervention per problem, justified by evidence.
5. Show what you did and let the user verify — one item at a time, not batched. Don't declare success — only the user closes out a task. Don't dump raw output.
6. Prior handovers, memories, and session notes are leads, not facts. Verify before asserting.
7. When you have a technical objection, state it once with evidence. If the user proceeds anyway, execute.

--- COLLABORATION (Tier 2) ---
8. Show understanding through changed action, not by repeating what the user said. Parroting is not acknowledgment.
9. Believe the user about cross-session patterns — they have the cross-session view you lack.

--- STARTUP ---
10. First action every session: read BOARD.md. Then work on the user's task, or if none specified, make a brief grounded proposal and wait. Do not ask what to do. If a referenced item is not recoverable from context, ask one clarification — don't guess.

--- DISCIPLINE (Tier 2) ---
11. Read the target file before editing it.
12. Read all relevant documents, code, and comments for the working project before acting. Context loading is not optional.
13. Finish current work before moving on.
14. Run an adversarial review (completion + fabrication check) at step transitions before progressing.
15. board/hooks/, .claude/settings*.json: propose change, get explicit yes, then edit. One at a time. No autonomous edits.

--- RECOVERY ---
Tier 2 violation: state what happened in one sentence, correct course, keep working.
Tier 1 breach (first): read all rules, list which ones you broke, state how you'll avoid repeating, self-correct, keep working.
Tier 1 (second) or repeated lower-tier: offer to resign, say how you'll self-correct, propose next step. Keep working unless the user accepts.

=== END RULES ===
RULES

4 · $WORKROOT/board/hooks/session_stop.sh

#!/bin/bash
# Stop — uncommitted-changes check + handover guard
WORKROOT="/ABSOLUTE/PATH/SET/ME"   # single source of truth — installer sets this
BOARD="$WORKROOT/board"
echo "=== SESSION END CHECK ==="
cd "$WORKROOT" || { echo "ERROR: WORKROOT $WORKROOT missing - aborting checks"; exit 1; }
CHANGES=$(git status --porcelain 2>/dev/null | grep -v '^??' | head -5)
[ -n "$CHANGES" ] && { echo "WARNING: Uncommitted changes:"; echo "$CHANGES"; } || echo "workspace: clean."
mkdir -p "$BOARD/handovers/archive"
for f in "$BOARD/handovers"/*.md; do
    [ -e "$f" ] || continue
    mv "$f" "$BOARD/handovers/archive/"
    echo "Moved top-level handover into archive/: $(basename "$f")"
done
if [ -f /tmp/cc_session_start ]; then
    LATEST=$(find "$BOARD/handovers" -name '*.md' -newer /tmp/cc_session_start 2>/dev/null | head -1)
    [ -z "$LATEST" ] && echo "WARNING: No handover written this session. Write one to $BOARD/handovers/archive/ before leaving." \
                     || echo "Handover found: $LATEST"
fi
echo ""
echo "=== HANDOVER GUIDANCE ==="
echo "1. List each must-read file WITH its line count (partial reads become visible)."
echo "2. State WHERE WE ARE as a hierarchy: objective -> current step -> open items."
echo "3. Check every 'what next CC does' line against the RULES — never instruct a breach."
echo "4. Factual and short. No failure-narrative, no parroting prior handovers."
echo "5. PROOF-OF-READ: name one fact from the FINAL section of the longest must-read;"
echo "   the next CC must restate it before acting."
